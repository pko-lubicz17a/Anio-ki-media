# aniolki-media

Pliki statyczne (MP3, MP4, grafiki, ikony) prywatnej, humorystycznej strony „Aniołki Dariusza”.
To NIE jest strona banku ani jego materiały. Bez danych klientów.

- `hymn/` – Radio Aniołki, Szafa grająca, hymn, klipy (dawny bucket Supabase `hymn`, te same ścieżki)
- `og/` – grafiki podglądu linku i ikony Radia (dawny bucket `og`)
- `icon/` – ikony aplikacji (dawna funkcja `aniolki-icon`)
